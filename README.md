# 프로젝트 서몬 — 프로토타입

> 유닛 소환 덱빌딩 × 보드 머지 로그라이크 디펜스. HTML5 프로토타입 (의존성 0).

**▶ 플레이**: https://kliesen923-ops.github.io/summon/

## 조작
- 상점 4슬롯: 골드로 구매(확정 T1 3G / 랜덤 T1 2G / 확정 T2 9G / 랜덤 T2 7G), 리롤 2G, 잠금 🔒 = 다음 웨이브에도 상점 유지.
- 골드: 웨이브 수입 +4G, 이자(보유 10G당 +1G, 최대 +5G), 판매 환급.
- 드래그: 배치 이동·스왑, 같은 유닛 포개기 = ★상승, 최대 성급 포개기 = 상위 티어 진화, 💰 존 = 판매.
- 준비 제한시간 30초 — 초과 시 자동 전투 시작. 전투는 자동 진행.

## 구성
- 챕터 9개 × 12웨이브 (4·8·12웨이브 = 보스). 진행도 localStorage 저장.
- 목숨 3칸 — 전멸 시 1칸 소멸 후 같은 웨이브 재정비·재도전, 남은 목숨 = 클리어 별점(⭐~⭐⭐⭐).
- 클래스 7종 × 유닛 35종 (Tier 1 = 7, Tier 2 = 28).
- `?demo=1` 쿼리 = 자동 진행 데모 모드.

## 개발
- 로컬 실행: `index.html` 더블클릭.
- 검증: `node test/test_logic.js` — 스탯표 대조·머지 규칙·봇 클리어 시뮬.
- 유닛 스프라이트 확인: `test/gallery.html`.
