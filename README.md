# 프로젝트 서몬 — 프로토타입

> 유닛 소환 덱빌딩 × 보드 머지 로그라이크 디펜스. HTML5 프로토타입 (의존성 0).

**▶ 플레이**: https://kliesen923-ops.github.io/summon/

## 조작
- 상점 4슬롯: 골드로 구매 — 확정 3G/9G/18G, 랜덤 2G/7G/14G (T1/T2/T3), 레벨업권 4G. 리롤 2G.
- 선택지별 잠금 🔒: 카드마다 토글, 잠긴 선택지는 웨이브 전환·리롤에도 유지.
- 골드: 웨이브 수입 +4G, 이자(보유 10G당 +1G, 최대 +5G), 판매 환급(💰 존 드래그, T1 2G / T2 6G / T3 12G / T4 24G / T5 48G — 레벨 무관).
- **레벨**: 유닛은 구매 시 Lv.1 — 웨이브 전투에 참여하면(승패 무관) +1Lv, 보스 웨이브 +2Lv, 최대 Lv.3.
- **진화**: 같은 티어 & 둘 다 Lv.Max인 유닛을 포개면 상위 티어 Lv.1로 진화 (T1→T2→T3→T4→T5, 클래스 조합으로 결과 결정). 그 외 드래그 포개기는 자리 스왑. 드래그 중 결과 미리보기 + 유닛 툴팁에 조합표 표시.
- **레벨업권 🎫**: 보드 1칸을 차지하는 아이템. 유닛에 드래그 = +1Lv 후 소모 (Max 유닛에는 사용 불가 → 스왑). 전투 중엔 숨겨지고 전투에 관여하지 않음.
- 보드 3×3 = 전장 겸 보관 (벤치 없음) — 9칸 자리 관리가 핵심.
- 유닛·상점 카드에 마우스 오버 = 스탯·스킬 툴팁.
- 준비 제한시간 30초 — 초과 시 자동 전투 시작. 전투는 자동 진행.
- 전투 45초 경과 시 ⚡광폭화(전원 공속·이속 2배), 90초 초과 = 패배.

## 구성
- 챕터 9개 × 12웨이브 (4·8·12웨이브 = 보스). 진행도 localStorage 저장.
- 챕터별 적 모디파이어: 방어·신속·원거리·재생·광포 — 후반 챕터는 중첩.
- 목숨 3칸 — 전멸 시 1칸 소멸 후 같은 웨이브 재정비·재도전(참여 유닛은 레벨업 유지), 남은 목숨 = 클리어 별점(⭐~⭐⭐⭐).
- 클래스 7종 × 유닛 119종 (Tier 1 = 7, Tier 2~5 = 각 28). T4·T5는 상점 미등장 — 진화로만 획득. T5(진홍테)는 T4 Max 두 체 조합의 최종 위계.
- `?demo=1` 쿼리 = 자동 진행 데모 모드.

## 개발

- 검증: `node test/test_logic.js` — 스탯표 대조·진화/레벨업 규칙·봇 클리어 시뮬.
- 유닛 스프라이트 확인: `test/gallery.html`.
