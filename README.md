# 프로젝트 서몬 — 프로토타입

> 유닛 소환 덱빌딩 × 보드 머지 로그라이크 디펜스. HTML5 프로토타입 (의존성 0).

**▶ 플레이**: https://kliesen923-ops.github.io/summon/

## 조작
- 드래프트 3택 1 → 유닛 자동 배치 (보드 → 벤치 순).
- 드래그: 배치 이동·스왑, 같은 유닛 포개기 = ★상승, 최대 성급 포개기 = 상위 티어 진화.
- 💰 존에 드래그 = 판매(골드), 드래프트 중 2G로 리롤.
- 전투는 자동 진행 — 준비 단계에서만 유닛 관리 가능.

## 구성
- 2챕터 × 3스테이지, 스테이지당 6웨이브(6 = 보스). 진행도 localStorage 저장.
- 클래스 7종 × 유닛 35종 (Tier 1 = 7, Tier 2 = 28).
- `?demo=1` 쿼리 = 자동 진행 데모 모드.

## 개발
- 로컬 실행: `index.html` 더블클릭.
- 검증: `node test/test_logic.js` — 스탯표 대조·머지 규칙·봇 클리어 시뮬.
- 유닛 스프라이트 확인: `test/gallery.html`.
